# Векторные эскизы (`public/art`)

SVG-файлы первой версии интерфейса. В текущем дизайне подключён только `logo-100loto.svg` — это иконка вкладки браузера в `frontend/index.html`. Остальные файлы оставлены как исходники и не используются:

- `sky-red.svg`, `sky-green.svg` — фоны тем;
- `balloon-red.svg`, `balloon-green.svg` — шары;
- `puzzle-gold.svg`, `puzzle-green.svg`, `puzzle-red.svg` — мотивы карточек бустеров.

Актуальные изображения (3D-шары, монеты, медали, билеты, пазл, облака, лента неба) и звуки лежат в [`../assets`](../assets).
