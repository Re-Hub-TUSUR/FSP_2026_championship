# Visual assets

Original vector assets for the Воздушный шар game interface. They are intentionally dependency-free SVGs and can be used as CSS backgrounds or `<img>` elements:

- `sky-red.svg` — red theme sunset mountain scene.
- `sky-green.svg` — green theme daylight hills scene.
- `balloon-red.svg`, `balloon-green.svg` — player balloon illustrations.
- `puzzle-*.svg` — selectable booster card motifs.

Suggested 100ЛОТО palette: `#17152b` ink, `#f7c948` gold, `#e53935` red, `#1fbe68` green, `#fff7df` warm surface. Keep text high contrast and preserve the 44px minimum touch target for controls.
